# Elin's Learning World

سلام! یک اپ‌وب فارسی برای کودکان دبستانی می‌سازم به نام "الین" (Aline).

این اپ کارهای زیر انجام می‌ده:

1. داستان‌های اخلاقی و سؤالات درسی تولید می‌کند

2. مکالمه سه‌مرحله‌ای: سلام → احوال‌پرسی → محتوای درسی/اخلاقی

3. داشبورد برای والدین و معلمین

4. کاملاً فارسی و RTL

صفحات اصلی:

1. / (Home) - انتخاب نقش: کودک یا والد

2. /settings (Settings) - والدین تنظیمات جلسه می‌کند

3. /chat (Chat) - کودک با الین صحبت می‌کند

4. /dashboard (Dashboard) - والدین پیشرفت را می‌بینند

ویژگی‌های کلیدی:

- 5 دکمه انتخاب حالت (mood) در greeting: 😄 🙂 😐 😢 😡

- Form برای والدین: نام کودک، نوع محتوا (درس/داستان)، کتاب، فصل، صفحه

- Chat interface با bubble messages

- Loading state: "الین در حال فکر کردن..."

- Dashboard charts و statistics

- Mobile-first responsive design

- Full RTL support برای فارسی

لطفاً:

1. React + TypeScript + Tailwind CSS استفاده کن

2. React Router برای صفحات

3. Mock data برای تست

4. Vazirmatn یا Arial Unicode MS برای فارسی

5. شروع کن با App.tsx و routing
